# ReadShelf — စာအုပ် Review Project

ReadShelf သည် စာအုပ်များကို စုစည်းခြင်း၊ PDF ဖတ်ခြင်း၊ Review ရေးသားခြင်းနှင့် Rating ပေးခြင်းတို့ ပြုလုပ်နိုင်သော Web Project ဖြစ်သည်။

Frontend၊ Backend API နှင့် Database ကို ချိတ်ဆက်အသုံးပြုထားသည်။

## အသုံးပြုထားသော နည်းပညာများ

- HTML — ဝက်ဘ်စာမျက်နှာ တည်ဆောက်ရန်။
- CSS နှင့် Tailwind CSS — အရောင်၊ Font နှင့် မျက်နှာပြင်အပြင်အဆင် ပြင်ဆင်ရန်။
- JavaScript — ခလုတ်၊ Form နှင့် API ချိတ်ဆက်မှုများအတွက်။
- Node.js နှင့် Express — Backend Server နှင့် API များအတွက်။
- SQLite — စာအုပ်နှင့် Review အချက်အလက်များ သိမ်းဆည်းရန်။

## လုပ်ဆောင်နိုင်သောအချက်များ

- စာအုပ်အသစ် ထည့်နိုင်သည်။
- စာအုပ်အချက်အလက် ပြင်နိုင်၊ ဖျက်နိုင်သည်။
- ထည့်ပေးထားသော စာအုပ် ၁၀ အုပ်ကို PDF အဖြစ် ဖတ်နိုင်သည်။
- စာအုပ်ဖတ်ရန် Link ထည့်နိုင်သည်။
- Review ရေးနိုင်၊ ပြင်နိုင်၊ ဖျက်နိုင်သည်။
- Rating ကို ၁ မှ ၅ အထိ ပေးနိုင်သည်။
- ပျမ်းမျှ Rating နှင့် Review အရေအတွက်ကို ကြည့်နိုင်သည်။
- မျက်နှာပြင်အကျယ်အလိုက် အပြင်အဆင် ပြောင်းလဲနိုင်သည်။
- Server ပြန်ဖွင့်သော်လည်း သိမ်းထားသောအချက်အလက်များ ဆက်ရှိနေသည်။

စာအုပ်တစ်အုပ်ကို ဖျက်လျှင် ထိုစာအုပ်၏ Review များပါ ဖျက်သွားမည်။

## လိုအပ်ချက်များ

- Node.js 22.13 သို့မဟုတ် အထက်။
- VS Code။
- Browser တစ်ခု။
- Package များ ပထမဆုံး Install လုပ်ချိန်တွင် Internet လိုအပ်သည်။

SQLite အတွက် သီးခြား Database Server တင်ရန် မလိုပါ။

## Project ဖွင့်နည်း

၁။ Project ZIP ကို ဖြည်ပါ။

၂။ VS Code မှ File → Open Folder ကိုနှိပ်ပြီး
package.json ရှိသော book-review Folder ကိုဖွင့်ပါ။

၃။ Terminal → New Terminal ကိုဖွင့်ပါ။

၄။ ပထမဆုံးအသုံးပြုချိန်တွင် အောက်ပါ Command ကိုရိုက်ပါ။

npm.cmd install
၅။ Server ဖွင့်ရန်—

npm.cmd start
၆။ Terminal တွင် ReadShelf is ready ဟုပေါ်လာလျှင်
Browser မှ အောက်ပါလိပ်စာကို ဖွင့်ပါ။

http://localhost:3000

အသုံးပြုနေစဉ် Terminal ကို ဖွင့်ထားရမည်။
Server ရပ်ရန် Ctrl ကိုဖိထားပြီး C နှိပ်ပါ။

နောက်တစ်ကြိမ် ပြန်ဖွင့်လျှင်—

npm.cmd start
ကိုသာ ရိုက်နိုင်သည်။
## Review ရေးနည်း

၁။ “Review ဖတ် / ရေး” ကိုနှိပ်ပါ။
၂။ နာမည်၊ Rating နှင့် Review ဖြည့်ပါ။
၃။ Publish review ကိုနှိပ်ပါ။

Edit ဖြင့် Review ပြင်နိုင်ပြီး Delete ဖြင့် ဖျက်နိုင်သည်။

ဥပမာ Rating ၅ နှင့် ၃ ပေးထားသော Review နှစ်ခုရှိလျှင်—

(5 + 3) / 2 = 4.0

ဟူသော ပျမ်းမျှ Rating ကို ပြသမည်။
server.js က Book Review app ရဲ့ Backend ကို လည်ပတ်ပေးတဲ့ဖိုင်ပါ။
အဓိက အလုပ် ၃ ခု
Website ဖွင့်ပေးတယ် — http://localhost:3000 ဝင်ရင် HTML၊ CSS၊ JavaScript နဲ့ PDF ဖိုင်တွေ ပို့ပေးတယ်။
API request တွေ လက်ခံတယ် — စာအုပ်ထည့်တာ၊ Review ရေးတာ၊ ပြင်တာ၊ ဖျက်တာတွေကို ကိုင်တွယ်တယ်။
Data စစ်ပြီး Database ကို ဖတ်/ရေးတယ် — ဥပမာ Rating က ၁–၅ အတွင်းလား စစ်ပြီး SQLite ထဲ သိမ်းတယ်။
